# ─────────────────────────────────────────────────────────────────────
# Distillation flag changes (vs. previous run):
#
# --distill_logit_weight 1.0
#     Unchanged numerically, but the KL it weights is now ~512× smaller
#     because the reduction bug is fixed. If this still feels too strong
#     after a few thousand steps, drop to 0.5.
#
# --distill_temperature 4.0
#     Softens both teacher and student distributions before computing KL,
#     so the student learns the relative ordering of *all* tokens
#     (the "dark knowledge"), not just the teacher's argmax. The KL is
#     multiplied by T^2 so the gradient magnitude is invariant to T.
#
# --distill_tick_aggregation all
#     KD is applied uniformly across every tick of the thought loop,
#     not just the last one. Essential when --per_tick_heads is enabled
#     (otherwise 7 of 8 heads never see KD signal); prevents the V-shaped
#     per-tick CE pattern observed in the previous run.
#
# --distill_feature_weight 0.0
#     The previous z-MSE term tried to align the FEEC-integrated student
#     latent with NemotronH's last hidden state via raw MSE. Those two
#     spaces have incompatible magnitude scales — that term contributed
#     noise, not signal. Disabled by default. To re-enable later with a
#     sensible objective, add:
#
#         --distill_feature_weight 0.1 \
#         --distill_feature_method cosine
#
#     Cosine similarity is magnitude-invariant and is the right choice
#     for cross-architecture distillation.
# ─────────────────────────────────────────────────────────────────────
