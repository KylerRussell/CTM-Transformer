# ── Dual-GPU Training (NCCL, no DDP) — consolidated layout ──────────────
# Same as before, but the entry-point module is now `ctm_transformer.train`
# with the `--multi_gpu` flag (replaces the old `ctm_transformer.train_offload`).
# Internally this still runs the dual-GPU NCCL-with-flat-allreduce path
# (worker_multi_gpu spawned via mp.spawn) — only the dispatch lives in train.py.
#
# Two model replicas process different micro-batches in parallel.
# Gradients flattened + allreduced via NCCL AFTER backward (no DDP).
# Effective batch size = 2 (1 per GPU).
#
# Throughput: ~0.8k tok/s (2× single GPU)
#
# To stop:
# pkill -9 -f "venv_nv/bin/python" && echo "Killed training processes" || echo "No training process found"
# fuser -k -9 29501/tcp && echo "Freed PyTorch distributed port" || echo "Port already free"

# --hebbian_bottleneck_dim 64 \

# --use_predictive_coding \
# --pc_target next_tick \
# --pc_loss_weight 0.05 \
# --pc_tick_aggregation all \

# --prospective_beta 2.0 \
