# ── Dual-GPU Training (NCCL, no DDP) — consolidated layout ──────────────
# Same as before, but the entry-point module is now `ctm_transformer.train`
# with the `--multi_gpu` flag (replaces the old `ctm_transformer.train_offload`).
# Internally this still runs the dual-GPU NCCL-with-flat-allreduce path
# (worker_multi_gpu spawned via mp.spawn) — only the dispatch lives in train.py.
#
# Two model replicas process different micro-batches in parallel.
# Gradients flattened + allreduced via NCCL AFTER backward (no DDP).
# Effective batch size = 2 (1 per GPU).
#
# Throughput: ~0.8k tok/s (2× single GPU)
#
# To stop:
# pkill -9 -f "venv_nv/bin/python" && echo "Killed training processes" || echo "No training process found"
# fuser -k -9 29501/tcp && echo "Freed PyTorch distributed port" || echo "Port already free"
#
# NOTE on R1/R2/R3 (2026-05-21): all three are integrated with Prospective
# Configuration (the memory-safe EM regime — KEEP --use_prospective_config here;
# the BPTT path at --max_thought_steps 100 OOMs on full-vocab per-tick logits).
#   R1 (--use_efe_controller): PonderNet halting adapted to the EM inference
#     relaxation — learns to stop the loop at the low-free-energy step
#     (objective Σ p_t·F_t + KL prior), early-exits the relaxation at eval.
#   R2 (--use_burstprop): the consolidation (learning) pass's Hebbian write is
#     burst-gated by the equilibrium PC error (apical credit). Needs HPC+Hebbian.
#   R3 (--use_meta_rl): prev-token reward/action input channel; adds a ~2x fwd
#     cost (a no_grad pre-pass; cheap here since amortized inference = 5 steps).
#
# NOTE on R4/R10/R11 (2026-05-22):
#   R11 (--btsp_weight_dependent): lives in HebbianSynapse → runs in the dual-GPU
#     path. Bidirectional weight-dependent + stochastic + (delay_shape=0 →
#     immediate) BTSP. Preserves plain --use_btsp when off.
#   R4 (--use_swr_tagging) + R10 (--use_rem_dreaming): the sleep micro-cycle is
#     now PORTED into the dual-GPU worker, so these — and --use_sleep_consolidation
#     / --use_swil / --use_prioritized_replay — run under --multi_gpu. Each rank
#     keeps its own episodic buffer; the sleep backward flat-allreduces its grads
#     (same as the main loop) so replica weights stay bit-identical. R10's REM
#     loss is folded into the sleep loss in-graph (gradient-reversal GAN) so the
#     generator/discriminator grads ride the same allreduce.
